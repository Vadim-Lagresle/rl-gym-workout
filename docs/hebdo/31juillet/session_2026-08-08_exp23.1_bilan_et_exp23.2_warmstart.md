### Le piège et le mécanisme (nouveau `--warm-start-dir`)

Relancer avec `--model-path <best>` aurait fait de TRL une référence = le best
lui-même (`grpo_trainer.py:971` : le ref model est rechargé depuis
`config._name_or_path`). Le nouveau flag fait donc :

1. trainer construit sur `--model-path` Qwen nu → ref model, tokenizer et moteur
   vLLM initialisés sur la base ; `sync_ref_model=False` (défaut) → ancre figée ;
2. injection des poids du best dans la POLITIQUE seule, après création
   (`load_state_dict(strict=False)` ; `lm_head.weight` manquant = tied, suit
   `embed_tokens`) ; TRL resynchronise vLLM avant la 1re génération
   (`_last_loaded_step=-1`) → rollouts du step 0 sur les poids injectés ;
3. `optimizer.pt` chargé à `on_train_begin` par `WarmStartOptimizerCallback`
   (l'optimiseur n'existe qu'au `train()` ; bnb surcharge `load_state_dict` et
   préserve les dtypes quantifiés).
